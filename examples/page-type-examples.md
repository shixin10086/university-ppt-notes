# 五类教学任务示例索引

生成一页备稿时，按照 [首次成文核心流程](../references/drafting-core.md) 判断主要教学任务，并且只读取下面一个对应文件。不要为了比较风格而同时加载多个示例。

- [普通知识或概念页](knowledge-concept.md)
- [原理图、流程图或示意图页](diagram-principle.md)
- [案例或场景页](case-scenario.md)
- [目录或章节过渡页](outline-transition.md)
- [小结页](summary-page.md)

样稿只用于校准知识展开方式、专业程度和讲述节奏。新课程的事实只能来自用户提供的PPT，不复制样稿内容或固定句式。
