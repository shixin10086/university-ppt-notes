# 核心写作规则

## 一、优先顺序

发生冲突时按以下顺序判断：

1. 忠实于PPT，事实和专业含义准确。
2. 让学生听懂本页要传达的知识。
3. 与前后页连贯，详略符合整讲结构。
4. 满足页面格式与字数边界。
5. 表达自然，符合大学教师授课口吻。

不要为了满足次要语言偏好而牺牲前面的目标。已经准确、顺畅、可讲的句子不要继续改。

## 二、默认格式与字数

中文、数字、英文及标点计入字数，模块标签和空白不计；用户另有约定时以用户设置为准。

| 页面类型 | 模块 | 默认字数 |
| --- | --- | --- |
| 普通内容页 | 引入 | 不超过60字，一句完整的话 |
| 普通内容页 | 备稿·简讲 | 100—110字 |
| 普通内容页 | 备稿·常规 | 110—130字 |
| 普通内容页 | 备稿·重点 | 130—160字 |
| 普通内容页 | 备稿·核心 | 160—190字 |
| 普通内容页 | 收束 | 35—45字，一句完整的话 |
| 封面 | 开场 | 150—200字 |
| 目录 | 讲授说明 | 80—120字 |
| 章节或小节页 | 过渡 | 60—90字 |
| 课堂思考、视频页 | 按任务 | 根据课堂动作灵活控制 |

普通页默认使用【引入】【备稿】【收束】。引入完整说清本页将讲什么；备稿完成解释；收束只总结当前页结论，不重复引入或提前讲下一页。

## 三、详略判断

篇幅取决于教学价值，而不是页面字数或版面复杂度。

- 核心概念、关键机制、首次出现的重要方法和承前启后的背景、小结页，可重点或核心讲。
- 承担必要知识解释的真实内容页不能因“流程多”而随意删减。
- 重复案例、重复流程、素材展示和仅用于过渡的页面可简讲，但应指出本页新增的条件、差异或结论。
- 同一机制首次出现时讲清，后续案例不重复完整过程，突出案例特色。

在整套分析中提出档位建议，由用户确认重点页和简讲页。不要用僵硬打分替代教师判断。

## 四、内容组织

- 备稿不是复述PPT结构，要解释“这页知识是什么意思、为什么重要、怎样理解”。
- 教师掌握讲述主动权，不用“图中列出了”“流程图分为”等句式机械带读版面。
- 真实流程图、原理图、示意图应围绕关键关系、因果或机制讲解；普通照片、装饰箭头、编号卡片和纯排版不必讲。
- 引入可以承接上一页，也可以直接进入本页，但必须是一句完整、自然的话，不能只说半截。
- 标题含“协同方式一”“场景二”等序号时，讲稿要明确点出序号和完整名称。
- 每个灾害场景的第一页要说明是第几个场景。
- 课堂思考页先提醒同学开始思考，不把“思考”改写成“设计”。

## 五、语言目标

采用通用大学教师口吻：专业、清楚、连贯，略带口语感但不是聊天。

- 句子按学生的听觉顺序展开，前后关系自然；连接词只在逻辑需要时使用，不追求数量。
- 可以把“道路连续性”表达为“道路是否连续”，但不能因口语化改变专业边界或因果关系。
- 避免设问、自问自答、口头禅、宣传式结论和无信息的总结腔。
- 不把多个不兼容的动作、主体或关系强塞进一句话。若一遍听不懂，调整信息顺序或拆分意思，而不是机械换同义词。

判断标准只有三个：内容准确、讲起来顺、学生听一遍能明白。
