# 首次成文核心流程

本文件只负责第一次成文。此时不要加载详细写作检查清单、质量反例或最终审计规则；它们在当前5页分别完成初稿后再使用。

## 一、逐页输入

保留前5页、当前5页和后5页用于判断关系，但每次只生成当前批次中的一页。该页只携带：

1. PPT文字与真实视觉证据；
2. 一句话核心教学认识，即学生听完应理解什么；
3. 前文已经讲清、当前页新增、后文再展开的内容；
4. 不得改变的术语、主体、条件、因果和专业边界；
5. 用户已经确认的页面格式、详略档位和目标字数；
6. 下列路由中唯一一个最接近的独立样稿。

## 二、样稿路由

- 知识、概念、背景或机制说明为主：读取 [知识或概念页](../examples/knowledge-concept.md)。
- 流程图、原理图、示意图或关键图表承载知识关系：读取 [图示或原理页](../examples/diagram-principle.md)。
- 案例、应用或具体场景为主：读取 [案例或场景页](../examples/case-scenario.md)。
- 目录、章节页或过渡页：读取 [目录或章节过渡页](../examples/outline-transition.md)。
- 小节小结或章节总结：读取 [小结页](../examples/summary-page.md)。

课堂思考、视频、封面等特殊页面没有合适样稿时，依据PPT任务和用户确认格式直接写，不加载最相似但功能不同的示例。

## 三、直接写成教师讲稿

- 先让学生接触需要理解的对象，再补充必要条件、原因、关系或结果；不要先汇报页面结构。
- 备稿要帮助学生理解知识，不能只是把PPT换成完整句子。
- 口语感来自清楚的听觉顺序和自然衔接，不使用设问、口头禅或聊天化措辞。
- 口语化不能改变专业含义；PPT不能支持的信息不补写。
- 真正承载知识的图示讲关键关系，普通图片和装饰排版不强行讲解。
- 引入完整进入本页，正文展开必要解释，收束只归纳本页形成的认识。

把目标字数视为写作预算，不为凑字数增加套话，也不为压字数删除关键条件。详细字数和格式核验在五页初稿完成后进行。

## 四、批次隔离

一页完成后先放置，再从该页自己的教学任务开始生成下一页。上一页只提供已经讲过的知识和必要承接，不能成为下一页的句式模板。五页全部完成后，才将它们组合起来进行详细规则核验、Humanize检测和连续试讲。
