# 伙伴Skill分工

## `ppt-speech-writer`

负责PPT层面的事实取证：文字提取、OOXML检查、整套渲染、OCR、视觉盘点、截图复核和最终备注写入。它不决定本课程的详略、教师口吻和审核节奏。

## `humanize`

负责发现AI式表达，如模板化开头、句间关系僵硬、机械列举和过度总结。默认先检测，再对明确有问题的句子做最小有效修改；不能把整篇讲稿无条件重写，也不能改变专业含义。

## `university-ppt-notes`

负责整讲教学主线、页面角色、详略、逐页格式、五页审核和用户反馈继承。内部教师口述检查与Humanize合并执行，避免同一批次经过多轮相互覆盖的改写。

## 调用顺序

1. 用 `ppt-speech-writer` 完成整套取证和渲染。
2. 由本Skill完成全讲分析并获得用户确认。
3. 本Skill直接生成当前批次。
4. 用 `humanize` 检测，并在同一次复核中完成教师口述检查。
5. 用户确认后写入累计稿。
6. 完稿后用 `ppt-speech-writer` 写入PPT备注。

任何伙伴Skill缺失都要向用户说明，不能静默替代。
