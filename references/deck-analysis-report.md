# 全讲分析报告

逐页写作前，必须先完成整套PPT提取、渲染和视觉复核，并向用户提交一份可确认的全讲分析。报告服务于后续判断，不写成逐页讲稿。

## 必须包含

1. **取证覆盖**：PPT文件名、总页数、文字提取和整套渲染是否完成，无法辨认的页面单独列出。
2. **教学主线**：用一段话说明课程从什么问题出发，经过哪些知识层次，最终落到什么结论或应用。
3. **章节与页面组结构**：按连续页段说明每组页面的教学任务及与前后组的关系。
4. **关键视觉**：列出真正需要讲解的流程图、原理图、示意图、图表或关键表格，并说明要解释的知识关系。
5. **详略规划**：给出简讲、常规、重点和核心页建议，特别标出背景页、小结页、重复案例和首次出现的关键机制。
6. **去重策略**：说明哪些机制首次讲清，后续哪些页面只讲新增条件或案例特色。
7. **首批定位**：说明P01—P05在全讲中的作用和生成时需要参考的后续内容。

## 用户确认

报告最后请用户确认教学主线、重点页、简讲页和视觉判断。用户确认前不得生成P01—P05。用户调整后，以确认结果作为本课程后续判断依据。

不使用机械评分强行决定详略；证据不足或页面作用有歧义时，在报告中明确说明并请用户决定。
